# Wireframes — EthosFinancial 1.0

Wireframes de baixa fidelidade das telas principais do sistema, em HTML autônomo (abra direto no navegador) e em PNG (usados na especificação formal, seção 24).

| Arquivo | Tela |
|---|---|
| `01_dashboard.html` / `.png` | Dashboard geral — indicadores e gráficos de inadimplência |
| `02_lista_alunos.html` / `.png` | Listagem de alunos — busca, filtros e situação |
| `03_importacao.html` / `.png` | Importação de planilha — upload, configuração e resumo |
| `04_relatorio_inadimplencia.html` / `.png` | Relatório de inadimplência — filtros avançados e ação em lote |
| `05_ficha_cobranca.html` / `.png` | Ficha de cobrança da matrícula — situação, TAGs, observações e histórico |

Esses arquivos são referência de estrutura e navegação (baixa fidelidade) — identidade visual, cores de marca e refinamento de UI ficam a cargo do time de design na etapa de UI final.
